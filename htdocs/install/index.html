How to Install

Motivnavi OS インストール方法

インストール用のUSBメモリを作り、タブレットにMotivnavi OSを導入するまでの手順です。

用意するもの

  • Windows PC
  • 16GB以上（できれば32GB以上）のUSBメモリ
  • Motivnavi OSを導入したい端末（動作環境を満たすもの）

Step 1Windows PCでの作業

  1. 最新のisoファイルをダウンロード

    ダウンロードページから、最新のisoファイルをダウンロードします。

    Google Driveは高速ですが、アクセス制限がかかる場合があります。その場合は、ミラーであるENOKI Drive側のリンクからダウンロードしてください。

  2. Rufusをダウンロード

    Rufus（rufus.ie）から、Rufusをダウンロードします。

  3. USBメモリを挿して、isoファイルを選択

    Windows PCに16GB（できれば32GB）以上のUSBメモリを挿し、Rufusを開いて、先ほどダウンロードしたisoファイルを選択します。

    USBメモリの中身はすべて消去されます。必要なデータは事前に別の場所へ移しておいてください。

  4. 書き込みが終わるまで待つ

    Rufusのスタートボタンを押すと書き込み（フラッシュ）が始まるので、終わるまで待ちます。

  5. USBメモリを導入したい端末に挿す

    完了したらUSBメモリを抜き、Motivnavi OSを導入したい端末に挿します。

Step 2導入したい端末での作業

  1. USBブートを最優先にする

    Motivnavi OSを導入したい端末のUEFI設定を開き、USBブートを最優先にします。

  2. 再起動してライブ起動環境に入る

    Motivnavi OSを導入したい端末を再起動すると、ライブ起動環境に入ります。

  3. 「Motivnavi OSをインストール」を選択

    数分待つとデスクトップが表示されるので、「Motivnavi OSをインストール」を選択します。

  4. インストーラーに沿ってインストール

    インストーラーの案内に沿って、インストールを開始します。
